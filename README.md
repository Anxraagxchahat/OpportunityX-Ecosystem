## About

**OpportunityX** is the main ecosystem for students, developers, builders, and young professionals.

The ecosystem is designed around discovering opportunities, building career assets, learning, creating, and connecting with a growing community.

The main public website is the central entry point for the ecosystem:

**https://opportunityx.co.in**

---

## Ecosystem

OpportunityX is being built as a multi-product ecosystem rather than a single application.

### Live

- **OpportunityX Radar** — opportunity discovery and tracking
- **OpportunityX Verify** — standalone verification platform
- **OpportunityX Resume** — resume-building product

### In Development

- **OpportunityX Learning Hub / Learn** — the current next development focus

### On Hold

- **OpportunityX Freelancing** — previously developed, currently paused

### Planned / Future

- **OpportunityX Jobs**
- **OpportunityX Portfolio**
- **OpportunityX Community**
- **OpportunityX AI**
- **OpportunityX Mentorship**
- **OpportunityX Support Platform**
- **OpportunityX Arena**

> **Roadmap disclaimer:** Planned projects represent our current vision and are not guaranteed to enter development or launch. Plans may change, be postponed, or be cancelled as priorities, resources, and feasibility evolve.

The roadmap is intentionally flexible. Products may move between **Live**, **In Development**, **Planned**, **On Hold**, and **Cancelled / Archived** as the ecosystem evolves.

## Technology

The ecosystem website is built with a modern React-based frontend architecture.

Core technologies include:

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React

The project also follows dedicated engineering documentation for:

- Product requirements
- Technical architecture
- Security & access
- Frontend specifications
- Feature tickets
- Continuous security & reliability guardrails
- Brand asset management

---

## Engineering Principles

OpportunityX aims to keep the public platform:

- **Fast** — performance is treated as a product feature
- **Accessible** — keyboard, contrast, semantics, and reduced-motion support matter
- **Secure** — secrets, input handling, content rendering, and deployment security are continuously reviewed
- **Maintainable** — reusable components and centralized configuration are preferred over duplication
- **Responsive** — layouts are designed intentionally for mobile, tablet, and desktop
- **Brand-consistent** — the official OpportunityX visual identity is preserved across the ecosystem

## Security

Security is treated as a continuous engineering requirement, not a final checklist.

Before production changes, review:

```text
docs/06-CONTINUOUS-SECURITY-AND-RELIABILITY-GUARDRAILS.md
```

The repository follows principles covering secret protection, input validation, XSS prevention, abuse protection, secure headers, HTTPS, dependency scanning, error handling, and future backend/database security.

Never commit secrets, private credentials, or production tokens.
